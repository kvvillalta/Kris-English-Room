# Kris English Room

## Aprende inglés de una manera práctica y personalizada

Kris English Room es un sitio web creado para ofrecer información sobre clases de inglés y presentar los servicios disponibles para estudiantes interesados en mejorar sus habilidades en el idioma.

El proyecto busca transmitir una imagen femenina, moderna y agradable, utilizando una combinación de colores suaves y una estructura sencilla para facilitar la navegación.

## 🌸 Características

- Página de inicio con presentación del proyecto.
- Sección informativa sobre las clases.
- Información sobre los servicios.
- Sección de contacto.
- Diseño adaptable a diferentes dispositivos.
- Navegación sencilla mediante HTML semántico.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages
- Visual Studio Code

## 🎨 Diseño

El sitio utiliza:

- Verde palo
- Rosado palo
- Celeste claro
- Blanco
- Times New Roman
