# Kris English Room

## Aprende inglés de una manera práctica y personalizada

Kris English Room es un sitio web creado para ofrecer información sobre clases de inglés y presentar los servicios disponibles para estudiantes interesados en mejorar sus habilidades en el idioma.

El proyecto busca transmitir una imagen femenina, moderna y agradable, utilizando una combinación de colores suaves y una estructura sencilla para facilitar la navegación.

## 🌸 Características

- Página de inicio con presentación del proyecto.
- Sección informativa sobre las clases.
- Página de servicios disponibles.
- Sección de planes de estudio.
- Galería de imágenes.
- Formulario de contacto funcional.
- Envío de mensajes mediante Web3Forms al correo de la clienta.
- Página de agradecimiento después de enviar el formulario.
- Menú de navegación adaptable a dispositivos móviles.
- Menú accesible mediante teclado.
- Uso de HTML semántico y atributos de accesibilidad.
- Diseño responsive para computadoras, tabletas y teléfonos.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Web3Forms
- Git
- GitHub
- GitHub Pages
- Visual Studio Code

## 🎨 Diseño

El sitio utiliza una combinación de colores suaves:

- Verde palo
- Rosado palo
- Celeste claro
- Blanco

La tipografía principal es Times New Roman. El diseño busca mantener una apariencia ordenada, femenina y agradable en todas las páginas.

## ♿ Accesibilidad y diseño responsive

Se implementó un menú móvil interactivo con JavaScript, utilizando controles accesibles y el atributo `aria-expanded` para comunicar su estado.

También se incorporaron ajustes para facilitar la navegación con teclado y adaptar la presentación del sitio a diferentes tamaños de pantalla.

## 📩 Formulario de contacto

El formulario de contacto utiliza Web3Forms para procesar los mensajes enviados desde el sitio web.

El correo de la clienta fue verificado y configurado como destinatario. Se realizó una prueba de envío y se confirmó la recepción del mensaje.
